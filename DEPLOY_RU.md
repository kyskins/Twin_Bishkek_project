# Развёртывание Twin Bishkek на VPS

Эта конфигурация запускает приложение в Docker, сохраняет базу SQLite в папке `data/` и автоматически включает HTTPS через Caddy. Она рассчитана на один экземпляр приложения: фоновый сборщик воздуха и погоды запускается внутри процесса сервера.

## Что понадобится

- VPS с Linux и публичным IPv4-адресом.
- Домен или поддомен, у которого DNS-запись указывает на IP сервера.
- Установленный на VPS Docker Engine с Docker Compose plugin.
- Открытые входящие порты TCP 80 и 443 (для HTTPS).

Обычная вкладка браузера не должна оставаться открытой, чтобы сохранялись данные Open-Meteo/CAMS. Текущий индекс пробок 2GIS всё ещё записывается только когда открыта карта: MapGL demo не предоставляет фоновую выгрузку истории по улицам.

## Первый запуск

1. Скопируйте папку `Twin_Bishkek_project` на VPS. Если нужно перенести уже накопленные записи, сначала остановите локальный сервер, затем скопируйте вместе с проектом папку `data/`.
2. Подключитесь к VPS по SSH и перейдите в папку проекта:

   ```sh
   cd Twin_Bishkek_project
   ```

3. Создайте настройки и откройте их редактором:

   ```sh
   cp .env.example .env
   nano .env
   ```

   В `TWINGIS_DOMAIN` укажите ваш домен. Поставьте UID и GID пользователя VPS, от имени которого будете запускать Docker Compose:

   ```sh
   id -u
   id -g
   ```

   Вставлять ключ 2GIS необязательно: без него откроется приложение и расчётный модуль, а карта предложит ввести ключ в интерфейсе. Если укажете `TWINGIS_MAPGL_KEY`, сначала разрешите в кабинете 2GIS origin `https://ваш-домен` для этого ключа.

4. Убедитесь, что папка с базой доступна пользователю запуска, и запустите приложение. Если при копировании папки база оказалась владельцем `root`, исправьте владельца:

   ```sh
   mkdir -p data
   sudo chown -R "$(id -u):$(id -g)" data
   docker compose up -d --build
   ```

5. Откройте `https://ваш-домен`. Проверить состояние приложения можно по адресу `https://ваш-домен/api/health`, а число сохранённых наблюдений — `https://ваш-домен/api/data-status`.

## Обновление и остановка

Обновить файлы приложения и пересобрать контейнер:

```sh
docker compose up -d --build
```

Посмотреть сообщения сервера и сборщика:

```sh
docker compose logs -f app
```

Остановить приложение:

```sh
docker compose down
```

База остаётся в `data/twin_bishkek.sqlite3` при пересборке и остановке. Не удаляйте эту папку, если хотите сохранить архив. Раз в день желательно копировать её на отдельное хранилище; перед ручным переносом остановите контейнер командой `docker compose down`, чтобы SQLite корректно сбросила WAL-файл.

## Что будет собираться

- Open-Meteo/CAMS: фоновый процесс запрашивает районы примерно раз в 15 минут и записывает новые временные снимки в SQLite. Частота появления новых данных у поставщика может быть ниже.
- 2GIS MapGL: индекс сохраняется, пока пользователь оставил карту открытой; одно и то же окно карты ограничено одним наблюдением на 15 минут.
- Публичный demo key для MapGL передаётся браузеру, так как этого требует клиентская карта. Ограничьте его разрешённым доменом в кабинете 2GIS и не вставляйте ключ в исходный код.

Развёртывание не создаёт доступ к закрытой или платной ленте трафика 2GIS и не превращает модель в самообучающийся ИИ. Оно обеспечивает непрерывную работу уже настроенного фонового сборщика и сохранение поступающих записей.
